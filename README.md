# Dean Worrels

Computer Science student at the University of South Florida focused on software engineering, full-stack development, data systems, automation, and AI-powered applications.

## Currently Building

### [Civtil](https://github.com/dworrels/civtil-case-study)

Platform for discovering local development projects from municipal permitting data.

Civtil collects, processes, standardizes, and organizes fragmented public building records to make local development information easier to search and understand.

**Focus:** Full-Stack Development · Data Engineering · Automation · Geospatial Data · AI

### [Nextscene](https://github.com/dworrels/nextscene)

Personalized movie recommendation system for discovering what to watch next.

Nextscene uses ratings, content information, embeddings, and recommendation techniques to generate personalized predictions and explain why a title may match a user's preferences.

**Focus:** Recommendation Systems · AI · Full-Stack Development · Data
